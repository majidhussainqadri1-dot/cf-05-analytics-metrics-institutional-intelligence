== Description ==

Includes governed event contracts, privacy-safe ingestion, derivative datasets, lineage, quality, backfills, versioned snapshots, query privacy/differencing controls, dashboards, reports, revocable encrypted exports, experiments, deletion, provider exit and restore evidence.

Runtime is disabled by default. Installation never authorizes production use.
