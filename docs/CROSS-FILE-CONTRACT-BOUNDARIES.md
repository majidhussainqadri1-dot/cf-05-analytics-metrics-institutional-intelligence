# Cross-File Contract Boundaries

- File 00 remains identity, role, guardian, suspension and entitlement authority.
- File 20 remains shell, route placement and global navigation owner.
- File 23 consumes authorized metric summaries; it does not gain raw analytics access.
- File 24 remains security/privacy/compliance assurance owner; CF-05 supplies evidence and consumes approved policy assertions.
- File 25 remains public visual/component owner; CF-05 supplies semantic status and aggregate data only.
- File 26 remains search/recommendation assignment and ranking authority; CF-05 analyzes aggregate outcomes without mutating treatment.
- Clinical, payment, message, media, support and publishing domains retain native source truth.

Every integration must use an approved versioned DTO/event/command contract. Availability detection never grants authorization, and stale analytics never grants access or mutates native state.
