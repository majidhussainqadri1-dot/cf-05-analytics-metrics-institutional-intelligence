# Security Policy

Do not open public issues containing secrets, real user data, event payloads, clinical information, payment information, identity evidence, private messages, infrastructure details or exploitable reproduction data.

Report suspected vulnerabilities privately to the platform owner. Rotate any exposed secret immediately and preserve minimal incident evidence.

This repository must contain public-safe source and documentation only. `SMAI_INGESTION_SECRET`, `SMAI_PSEUDONYM_KEY`, provider credentials, real datasets and operational incident playbooks must remain outside Git.
